# Project Plan

## Project Objective

The current project objective is to complete Objective 1 for HIT140 Assessment 2 by conducting four distinct data analysis tasks related to the FIFA World Cup 2026 project.

## Current Assessment Scope

This phase covers Assessment 2 only and applies concepts taught in Weeks 1–5. Python will be used for data wrangling and statistical analysis. Each of the four analytic tasks will include data preparation and wrangling, descriptive statistics, a confidence interval, and either a one-sample or two-sample t-test. The output will be the group presentation and supporting project repository.
